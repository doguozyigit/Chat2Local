# My task list

Build a single-file task list called `index.html` that I can open directly in a browser on my laptop.

- Let me add a task, mark it complete, and delete it.
- Save tasks in the browser so refreshing does not lose them.
- Work comfortably on a narrow phone-sized screen and a laptop.
- Include a clear empty state and labeled controls usable with a keyboard.
- Use plain HTML, CSS, and JavaScript. No downloads or external dependencies.

Start with no tasks. Treat everything I type as text, not HTML.
